# Financial Crime AI Learning Roadmap

A focused 6-month learning and build roadmap designed to develop practical AI, automation and analytics capability for Financial Crime transformation.

This repository tracks my progression from Python and data analysis fundamentals through to RAG, agentic workflows, MCP and Financial Crime AI prototypes.

---

## Objective

To build practical capability at the intersection of:

- Financial Crime Transformation
- AML and Sanctions Analytics
- Financial Intelligence and Threat Analysis
- AI-Enabled Investigation Workflows
- RAG, Agents and Workflow Automation
- Python, Pandas and API Integration

The goal is not to become a generic ML Engineer, but to become a Financial Crime AI Transformation practitioner who can understand, design and prototype AI-enabled compliance and investigation solutions.

---

# 6-Month Roadmap

## Phase 1: Python, Pandas, APIs and Automation

**Timeline:** Months 1-2

### Focus Areas

- Python fundamentals
- Pandas for data analysis
- JSON and file handling
- API calls and response handling
- Basic workflow automation

### Learning Outcomes

By the end of this phase, I should be able to:

- Read and process CSV files
- Clean and transform alert or transaction datasets
- Use Pandas for filtering, grouping and summarising data
- Call external APIs using Python
- Automate simple Financial Crime analysis tasks

### Practice Projects

- AML Alert Data Analysis Notebook
- Sanctions Screening Results Summary
- Transaction Risk Pattern Explorer
- Basic API Enrichment Workflow

---

## Phase 2: RAG and Financial Crime Knowledge Retrieval

**Timeline:** Months 3-4

### Focus Areas

- Retrieval-Augmented Generation (RAG)
- Embeddings
- Document Chunking
- Semantic Search
- Vector Databases
- Prompt Design for Grounded Answers

### Learning Outcomes

By the end of this phase, I should be able to:

- Build a simple RAG pipeline
- Load Financial Crime guidance documents
- Retrieve relevant policy or regulatory content
- Generate grounded summaries from source material
- Understand where RAG can support compliance and investigation workflows

### Practice Projects

- Financial Crime Policy Copilot
- FATF/FCA Guidance Q&A Assistant
- AML Typology Knowledge Base
- Investigator Policy Search Tool

---

## Phase 3: Agents, MCP and Workflow Orchestration

**Timeline:** Months 5-6

### Focus Areas

- AI Agents
- Tool Calling
- LangGraph
- Multi-Step Workflows
- Human-in-the-Loop Review
- Model Context Protocol (MCP)
- Agent Governance and Control

### Learning Outcomes

By the end of this phase, I should be able to:

- Design agentic investigation workflows
- Connect AI assistants to tools and data sources
- Build controlled multi-step workflows
- Understand MCP at a practical level
- Prototype Financial Crime investigation support tools

### Practice Projects

- AML Investigator Copilot
- Alert Triage Assistant
- SAR/Case Summary Drafting Assistant
- Financial Crime Workflow Agent
- Human-in-the-Loop Investigation Review Flow
